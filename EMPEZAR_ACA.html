Cómo empezar

Aprendizaje Automático y Grandes Datos · Inteligencia Artificial y Aprendizaje Automático

Esta carpeta ya tiene todo lo que hace falta: el cuaderno, los datos y la lista de bibliotecas. No hay que descargar nada más.

Elegí un camino y seguilo hasta el final. Los cuatro llegan al mismo lugar. No hace falta hacer más de uno.
  1. Windows
  2. Windows con Visual Studio Code
  3. Mac con Visual Studio Code
  4. Docker, en cualquier sistema
  5. Google Colab, sin instalar nada

¿No sabés cuál elegir? Si nunca instalaste Python y solo querés que funcione hoy, andá al camino 5, Colab. Si querés trabajar en tu computadora, el camino 1.

1 · Windows

  1. Abrí esta carpeta en el Explorador de archivos.
  2. Hacé clic en la barra de dirección de arriba, escribí cmd y apretá Enter. Se abre una ventana negra parada en esta carpeta.
  3. Escribí estas líneas, una por vez, esperando que termine cada una:
py -3.13 -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
python scripts\verificar_entorno.py
Si la primera línea dice que no encuentra esa versión, probá con py -3.12 -m venv .venv y después con py -3.11 -m venv .venv. Si ninguna funciona, entrá a python.org, bajá Python 3.13 —no la última— e instalala tildando Add python.exe to PATH. No desinstales nada de lo que ya tengas: en una misma computadora conviven varias versiones sin molestarse.
Después de la segunda línea, adelante del cursor tiene que aparecer (.venv). La última línea tiene que terminar diciendo RESULTADO: entorno correcto.
  1. Para abrir el cuaderno, escribí jupyter lab y se abre solo en el navegador.

2 · Windows con Visual Studio Code

  1. Archivo → Abrir carpeta, y elegí esta carpeta. A la izquierda tienen que verse el cuaderno y la carpeta datos.
  2. Si te ofrece instalar las extensiones Python y Jupyter, aceptá.
  3. Abrí la terminal con Ctrl + Ñ y escribí, una línea por vez:
py -3.13 -m venv .venv
.venv\Scripts\python -m pip install -r requirements.txt
  1. Abrí el archivo .ipynb con un clic.
  2. Arriba a la derecha dice Seleccionar kernel. Clic ahí, Entornos de Python, y elegí .venv.
  3. Corré la primera celda con el triangulito de la izquierda.
No escribas activate en Visual Studio Code. No hace falta, y en muchas máquinas PowerShell lo bloquea. Por eso la instalación usa .venv\Scripts\python directamente.

Si no aparece .venv en la lista de kernels, cerrá y volvé a abrir Visual Studio Code. Si sigue sin aparecer, Ctrl+Shift+P → Python: Select Interpreter → Enter interpreter path, y apuntá a .venv\Scripts\python.exe dentro de esta carpeta.

3 · Mac con Visual Studio Code

  1. Archivo → Abrir carpeta, y elegí esta carpeta.
  2. Si te ofrece instalar las extensiones Python y Jupyter, aceptá.
  3. Abrí la terminal desde Terminal → Nueva terminal y escribí, una línea por vez:
python3.13 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
  1. Abrí el archivo .ipynb con un clic.
  2. Arriba a la derecha, Seleccionar kernel → Entornos de Python → .venv.
  3. Corré la primera celda.
Si dice command not found, probá con python3.12 y después con python3. Si ninguno funciona, entrá a python.org, bajá Python 3.13 para macOS e instalalo. No desinstales nada.

Si python3 a secas te da 3.14, el entorno se crea pero después falla la instalación de una biblioteca. En ese caso hay que instalar la 3.13 y escribir python3.13 explícitamente.

4 · Docker, en cualquier sistema

  1. Abrí Docker Desktop y esperá a que abajo a la izquierda diga Engine running.
  2. Abrí una terminal parada en esta carpeta. En Windows: clic en la barra de dirección del Explorador, escribir cmd y Enter. En Mac: clic derecho sobre la carpeta → Servicios → Nueva terminal en la carpeta.
  3. Escribí esta línea. La primera vez tarda entre 5 y 15 minutos, porque baja e instala todo:
docker build -t unraf-aa .
  1. Cuando termine, escribí la que corresponda a tu sistema:
docker run --rm -p 8888:8888 -v "%cd%":/trabajo unraf-aa     (Windows)
docker run --rm -p 8888:8888 -v "$PWD":/trabajo unraf-aa     (Mac)
  1. Abrí el navegador en http://localhost:8888. Ahí está el cuaderno.
Todo lo que escribas queda guardado en esta carpeta, en tu computadora. Para cortar el servidor, Ctrl+C en la terminal.

5 · Google Colab, sin instalar nada

Corre en el navegador, con una cuenta de Google. No hay que instalar Python ni nada más. Es el camino más rápido para empezar hoy.

  1. Entrá a colab.research.google.com.
  2. Archivo → Subir cuaderno, y elegí el archivo .ipynb de esta carpeta.
  3. A la izquierda hay un ícono de carpeta. Hacé clic, y después en el ícono de subir archivo. Subí el zip completo, el mismo que descargaste.
  4. Arriba de todo, insertá una celda nueva con + Código y pegá esto, reemplazando el nombre del zip por el que subiste:
!unzip -q -o NOMBRE_DEL_ZIP.zip -d /content
!pip install -q ucimlrepo fg-data-profiling mlxtend
  1. Corré esa celda primero, y después seguí con el cuaderno desde el principio.
Colab borra los archivos cuando se cierra la sesión. Lo que escribas en el cuaderno se guarda en tu Google Drive, pero los archivos subidos no. Cada vez que volvés, hay que repetir los pasos 3 y 4.

Si alguna celda dice No module named seguido de un nombre, agregá una celda con !pip install -q y ese nombre, corréla, y seguí.
En Colab los datos se descargan de internet la primera vez que se usan, en lugar de salir de la carpeta. Es normal que la primera carga tarde unos segundos.

Si algo falla

No repitas los pasos ni pruebes otro camino. Copiá la última línea del error, la que empieza con una palabra en mayúsculas, y mandala. Con esa línea alcanza para saber qué pasó.

Qué hay en esta carpeta

  • .ipynb — el cuaderno del laboratorio.
  • datos/ — el catálogo de conjuntos de la materia, con los datos ya descargados. No la muevas ni le cambies el nombre: el cuaderno la busca al lado suyo.
  • requirements.txt — la lista de bibliotecas y sus versiones.
  • scripts/verificar_entorno.py — comprueba que quedó todo bien.
  • Dockerfile — solo se usa en el camino 4.
